# 🎓 College Copilot

A simple and user-friendly college information assistant built with Python and Streamlit.

College Copilot brings common college information into one place, including faculty, classrooms, assignments, attendance, timetable, notices, and campus contacts.

## ✨ Features

* 🏠 **Dashboard** — Quick overview of important college information
* ✨ **My Day** — View today's classes, attendance, and assignments
* 📅 **Timetable** — Check the class schedule
* 📝 **Assignments** — View upcoming academic work
* 📊 **Attendance** — Track attendance
* 📢 **Notices** — View important college announcements
* 👩‍🏫 **Faculty** — Find faculty information
* 🏫 **Campus** — Find rooms and campus contacts
* 🤖 **College Copilot** — Ask questions about college information

## 🤖 College Copilot

The built-in Copilot can respond to questions related to:

* Faculty
* Rooms and locations
* Assignments
* Attendance
* Timetable
* Notices
* Campus contacts
* My Day

### Example questions

> Who teaches Physics?

> Where is Physics?

> Show my attendance

> What assignments do I have?

> Show my timetable

## ▶️ How to Run

### 1. Install Python

Make sure Python is installed on your computer.

### 2. Open the project folder

Open a terminal or PowerShell inside the project folder.

### 3. Install the required package

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python -m streamlit run app.py
```

The application will open in your web browser.
